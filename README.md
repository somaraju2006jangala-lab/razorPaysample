# Fresh-Cart Razorpay Payment Gateway Template

Welcome to the standalone Fresh-Cart Razorpay Payment Gateway project.

The complete project is located in `freshcart-razorpay-template/`.

## Quick Start

### 1. Start Backend Server (Port 5001)
```bash
cd freshcart-razorpay-template/backend
npm install
npm test            # Run 16-scenario test suite
npm run dev         # Starts backend on http://localhost:5001
```

### 2. Start Frontend Web Interface (Port 5173)
```bash
cd freshcart-razorpay-template/frontend
npm install
npm run dev         # Starts UI on http://localhost:5173
```

Visit **http://localhost:5173** to view the Fresh-Cart Payment Gateway.  
Admin Portal: **http://localhost:5173/admin** (Login: `admin` / `admin@freshcart2026`).

Refer to `freshcart-razorpay-template/README.md` and `freshcart-razorpay-template/docs/` for comprehensive guides.
